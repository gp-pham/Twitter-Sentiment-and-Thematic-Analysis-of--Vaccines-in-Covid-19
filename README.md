# Twitter-Sentiment-and-Thematic-Analysis-of-Covid-19
Sentiment and thematic analysis of tweets on Twitter about vaccinations in 2020-2021


RQ: what are the most discussed topics surrounding COvid-19 vaccines on Twitter during 2020-2021? And what are the general sentiment towards these topics?

dataset: https://www.kaggle.com/datasets/gpreda/all-covid19-vaccines-tweets
method: spaCy NLP library, TF-IDF to cluster keywords and topics; VADER for sentiment analysis and emotional valence
for topic creation: refer to papers(e.g. https://www.jmir.org/2021/6/e24435/) to identify possible topics
